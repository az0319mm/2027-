# 1단계: Photoshop 플러그인 설치·테스트 가이드 (맥북)

이 단계에서는 **Python 설치가 필요 없습니다.** Photoshop과 Adobe 무료 도구 하나만 있으면 됩니다.
목표는 플러그인이 실제 Photoshop에서 아래 6가지를 해내는지 확인하는 것입니다.

1. 열려 있는 PSD 문서 인식
2. 모든 레이어·그룹 탐색
3. 레이어 픽셀 읽기
4. **복제본**에 테스트용 1픽셀 수정 (원본은 건드리지 않음)
5. 새 PSD 파일로 저장 (`원본이름_UXPTEST.psd`)
6. 저장한 파일을 다시 열어 레이어 구조와 픽셀이 보존됐는지 자동 검증

---

## 준비물
- **Photoshop 2023 (버전 24.4) 이상**
  - 버전 확인: 메뉴 **Photoshop → Photoshop 정보**
  - 24.4보다 낮으면 Creative Cloud 앱에서 업데이트하세요. 픽셀 읽기·쓰기 기능이 24.4부터 지원됩니다.
- **UXP Developer Tools** (Adobe 무료 도구)
  1. **Creative Cloud 앱**을 엽니다.
  2. 왼쪽 **모든 앱(All apps)**에서 검색창에 `UXP`를 입력합니다.
  3. **UXP Developer Tools**의 **설치**를 누릅니다.
- 이 프로그램 폴더: GitHub에서 **Code → Download ZIP**으로 받아 압축을 풉니다. 바탕화면에 두면 편합니다.

## 설치 (처음 한 번만)
1. **Photoshop 개발자 모드 켜기**
   - Photoshop 메뉴 **Photoshop → 설정(환경설정) → 플러그인**
   - **"개발자 모드 활성화(Enable Developer Mode)"**를 체크하고 Photoshop을 **재시작**합니다.
2. **UXP Developer Tools**를 엽니다.
   - Photoshop이 켜져 있으면 위쪽 "Connected apps"에 Photoshop이 보입니다.
3. 오른쪽 위 **Add Plugin**을 누르고, 받은 폴더의 `uxp-plugin/manifest.json`을 선택합니다.
4. 목록에 생긴 **PSD 졸업작품 클린업** 줄의 오른쪽 **••• → Load**를 누릅니다.
   - 처음에 권한 허용 창이 뜨면 **허용**을 누릅니다. 파일 접근 권한(새 PSD 저장용)입니다.
5. Photoshop 메뉴 **플러그인 → PSD 클린업**을 누르면 패널이 열립니다.

## 1단계 테스트 실행
1. **연습용 PSD**를 Photoshop에서 엽니다. 처음에는 중요한 원본 대신 **복사본 파일**로 하시길 권합니다.
   - 문서가 **저장된 상태**여야 합니다(제목에 `*` 표시가 없어야 함).
2. 패널에서 **"1단계 테스트 실행"**을 누릅니다.
3. 잠시 뒤 아래 칸에 ✅ / ❌ 결과가 나옵니다. 문서가 크면 1~2분 걸릴 수 있습니다.
4. 원본 PSD가 있는 폴더에 `원본이름_UXPTEST.psd`가 새로 생깁니다. 원본 파일은 바뀌지 않습니다.
5. **결과 화면을 캡처해서 보내 주세요.** 실패 항목이 있으면 그 내용을 보고 고치겠습니다.

### 결과 항목 설명
| 단계 | 확인 내용 |
|---|---|
| 1 | 문서 이름·크기·해상도·색상 모드·비트·색상 프로파일을 읽었는지, 원본 파일 지문(바뀌었는지 확인용)을 기록했는지 |
| 2 | 모든 레이어·그룹 수와 종류 |
| 3 | 픽셀 레이어를 모두 읽었는지 |
| 4 | **복제본**의 레이어 하나에서 가운데 근처 1픽셀의 색을 반전 (원본 문서는 그대로) |
| 5 | 새 PSD로 저장했는지, **원본 파일 지문이 그대로인지** |
| 6 | 다시 연 파일의 캔버스 크기·해상도·모드·비트·프로파일, 레이어 이름·그룹·순서·가시성·불투명도·칠 불투명도·블렌드 모드·클리핑·잠금·위치가 원본과 같은지, 테스트 픽셀 **1개만** 정확한 값으로 바뀌었는지, 나머지 레이어 픽셀이 모두 그대로인지 |

### 자주 생길 수 있는 문제
- **패널이 메뉴에 없음**: 개발자 모드를 켠 뒤 Photoshop을 재시작했는지, UXP Developer Tools에서 **Load**를 눌렀는지 확인하세요.
- **"문서를 먼저 저장해 주세요"**: 새 문서는 한 번 저장해야 같은 폴더에 테스트 파일을 만들 수 있습니다.
- **"잠기지 않은 픽셀 레이어가 없습니다"**: 모든 레이어가 잠겨 있으면 테스트할 곳이 없습니다. 연습용 파일에서 레이어 하나의 잠금을 풀어 주세요.
- **저장 단계에서 권한 오류**: 권한 허용 창에서 "허용"을 눌렀는지 확인하세요. 문서가 외장 디스크나 클라우드 폴더에 있으면 데스크톱 폴더로 옮겨서 해 보세요.

## 개발 상태 (솔직한 현황)
| 항목 | 상태 |
|---|---|
| 플러그인 코드 (1단계) | 작성 완료. Adobe 공식 타입 정의(`@types/photoshop` 27.11, `@adobe/cc-ext-uxp-types` 7.3.1)로 API 이름·옵션을 확인했습니다 |
| 모의 Photoshop 테스트 | 정상 저장 / 저장 중 속성이 바뀐 불량 파일 감지 / 모든 레이어가 잠긴 문서, 3가지 경우 모두 의도대로 동작 |
| **실제 Photoshop 실행** | **미검증.** 이 개발 환경에는 Photoshop이 없습니다. 위 테스트 결과를 보내 주시면 확인됩니다 |
| Windows | 미검증 (파일 경로 처리 코드는 있음) |
| 2단계 자동 클린업 | 알고리즘(Python)은 구현·테스트되어 있습니다. 1단계가 실제 Photoshop에서 통과하면 플러그인과 정식으로 연결합니다 |

### 2단계 연결 방식 (예정)
- 플러그인(UXP)은 보안상 Python 프로그램을 직접 실행할 수 없습니다.
- 그래서 내 컴퓨터 안에서만 접속되는 **로컬 서버(127.0.0.1)**와 통신합니다. 외부 인터넷으로는 아무것도 보내지 않습니다. 서버는 `run_mac.command`를 더블클릭해 켭니다.
- 수정 결과 적용 방식:
  1. Python이 고칠 픽셀을 계산합니다.
  2. 플러그인이 Photoshop의 픽셀 쓰기 기능으로 **복제본**에 적용합니다.
  3. Photoshop이 새 PSD로 저장합니다.
  4. 1단계와 같은 방식으로 검증합니다.
