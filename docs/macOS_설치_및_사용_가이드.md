# PSD 클린업 — macOS 설치 및 사용 가이드

코딩을 몰라도 따라 할 수 있도록 만든 안내서입니다. 처음 한 번만 설치하면, 이후로는 **Photoshop 패널의 버튼만** 누르면 됩니다.
터미널 명령은 입력하지 않아도 됩니다.

## 구성
- **Photoshop 패널(UXP 플러그인)**
  - 레이어 픽셀을 꺼내고, 고친 픽셀을 **복제본의 원래 위치**에 써 넣습니다.
  - 새 PSD로 저장하고 다시 열어 검증합니다.
- **클린업 엔진(Python)**
  - 어패럴과 인테리어 규칙으로 고칠 곳을 계산합니다.
  - Mac에 로그인할 때마다 자동으로 켜지는 백그라운드 프로그램입니다.
- 둘은 내 Mac의 **`~/PSDCleanup` 폴더로 파일을 주고받습니다.**
  - 인터넷으로는 아무것도 보내지 않습니다.
  - 작업 파일은 처리가 끝나면 지워지고, 혹시 남아도 24시간 뒤 자동으로 정리됩니다.

## 준비물
| 항목 | 조건 | 확인 방법 |
|---|---|---|
| Mac | Apple Silicon(M1~) 또는 Intel, macOS 11 이상 | 화면 왼쪽 위  → 이 Mac에 관하여 |
| Photoshop | **2023 (24.4) 이상** | Photoshop → Photoshop 정보 |
| Python | 3.10 이상 (없으면 설치 파일이 설치 페이지를 열어 줌) | 설치 파일이 자동 확인 |
| UXP Developer Tools | Adobe 무료 도구 | Creative Cloud 앱 → 모든 앱 → `UXP` 검색 → 설치 |

> Python을 새로 설치할 때는 python.org의 **"macOS 64-bit universal2 installer"**를 받으세요. Apple Silicon과 Intel 모두에서 동작합니다.

## 설치 (처음 한 번)
1. GitHub에서 **Code → Download ZIP**으로 받고 압축을 풉니다. 이 브랜치에서 받아야 합니다: https://github.com/az0319mm/2027-/tree/claude/photoshop-psd-cleanup-ermtuq
2. 압축을 푼 폴더에서 **`PSD 클린업 엔진 설치.command`를 우클릭 → 열기**를 누릅니다.
   - "확인되지 않은 개발자" 경고가 뜨면 **열기**를 누릅니다.
   - 그래도 막히면 **시스템 설정 → 개인정보 보호 및 보안**의 아래쪽에서 **"그래도 열기"**를 누릅니다.
   - 터미널 창이 열리며 다음 순서로 자동 진행됩니다.
     1. Mac 칩, macOS, Photoshop 버전을 표시합니다.
     2. Python을 확인합니다.
     3. 필요한 부품을 설치합니다(처음 1~3분).
     4. 엔진 자가 테스트를 합니다.
     5. 백그라운드 엔진을 등록합니다.
   - **"✅ 설치 완료"**가 나오면 Enter를 눌러 창을 닫습니다.
3. **Photoshop 개발자 모드**를 켭니다: Photoshop → 설정 → 플러그인 → **"개발자 모드 활성화"** 체크 → Photoshop 재시작.
4. **UXP Developer Tools**를 열고 **Add Plugin**을 누른 뒤 `uxp-plugin/manifest.json`을 선택하고 **Load**를 누릅니다.
5. Photoshop 메뉴 **플러그인 → PSD 클린업**을 눌러 패널을 엽니다.
6. 패널에서 **"환경 확인"**을 누르면 칩, macOS, Photoshop, 엔진 상태가 표시됩니다. 모두 ✅이면 준비 완료입니다.

## 사용 순서
1. 클린업할 PSD를 Photoshop에서 엽니다.
2. **모드**를 고릅니다.
   - **어패럴**: "반복된 1픽셀도 고치기"는 보고서에서 '의도적 반복'이 복사된 실수로 보일 때만 켭니다.
   - **인테리어**: 표현 방식(수채화, 색연필, 크레파스, 디지털 색면)을 고르고, 필요하면 "스캔 종이 배경 지우기"를 켭니다.
   - **리핏**: 해당 방향을 고릅니다.
3. **① 현재 PSD 분석**: 아무것도 고치지 않고 문제 목록만 봅니다.
4. **② 자동 클린업**: `원본이름_CLEAN`이라는 **복제본 문서**가 생기고, 확실한 오류만 고쳐집니다.
   - 고친 직후 픽셀을 다시 읽어 엔진 계산과 비교합니다. 하나라도 다르면 **모두 취소**합니다.
5. **③ 전후 비교**: 고친 곳을 확대한 비교 이미지가 열립니다(수정 전 / 수정 후 / 바뀐 픽셀 빨강).
6. **④ 남은 오류 재검사**: 복제본을 다시 검사해서 남은 문제를 보여 줍니다.
7. **⑤ 새 PSD로 저장**: `원본이름_CLEAN.psd`로 저장하고 다시 열어 검증합니다.
   - 레이어 구조, 캔버스, 프로파일, 픽셀을 확인합니다.
   - 검증에 실패하면 파일 이름에 `_VERIFY_FAILED`가 붙습니다.
8. **⑥ 검수 보고서 저장**: PSD 옆에 `원본이름_QA.html`을 저장합니다.

**원본 PSD는 어떤 경우에도 바뀌지 않습니다.**

## 처리 규칙 요약
- **처리하는 레이어**: 일반 픽셀 레이어(RGB 8비트).
- **건너뛰고 보고만 하는 레이어**: 스마트 오브젝트, 텍스트, 조정·칠 레이어, 레이어 마스크가 있는 레이어, 잠긴 레이어, 16/32비트 문서.
- **수정 방식**: 블러, 리샘플링, 전체 필터는 쓰지 않습니다. 오류로 확정된 1~몇 픽셀만 **이미 주변에 있는 색**으로 고치거나 투명 처리합니다.
- **어패럴**:
  - 고치는 것: 의도하지 않은 1픽셀, 잘못 칠한 색, 회전으로 깨진 곧은 경계·대각선 경계, 분판(레이어 하나 = 색 하나) 사이 1픽셀 이동(구멍·겹침이 생기지 않게).
  - 지키는 것: 반복되는 의도적 1픽셀, 곡선 꼭짓점, 뾰족한 끝, 가는 선.
- **인테리어**:
  - 고치는 것: 모티브와 떨어진 잔여 점과 옅은 지우개 흔적, (선택 시) 스캔 종이 배경.
  - 지키는 것: 수채화 번짐, 붓 터치, 질감.
  - 보고만 하는 것: 외곽 종이색, 도장툴 흔적, 각진 외곽, 1px 직선 자국, 리핏 어긋남.

## 문제 해결
| 증상 | 해결 |
|---|---|
| 패널에서 "엔진 꺼짐" | `PSD 클린업 엔진 설치.command`를 다시 실행하세요. 로그는 `~/PSDCleanup/engine.log`에 있습니다 |
| 패널이 메뉴에 없음 | 개발자 모드를 켠 뒤 Photoshop을 재시작했는지, UXP Developer Tools에서 Load를 눌렀는지 확인 |
| 파일 권한 질문 창 | "허용"을 누르세요(작업 폴더와 PSD 옆 저장용) |
| 엔진 제거 | `PSD 클린업 엔진 제거.command` 실행 |

## 검증 현황 (솔직한 현황)
| 항목 | 상태 |
|---|---|
| 클린업 엔진(어패럴/인테리어) | 자동 테스트 통과. 합성 사례, 기준 PDF 사례 재현, 실제 분판 PSD 1개로 검증 |
| 플러그인 ↔ 엔진 파일 교환 | 모의 Photoshop + 실제 엔진으로 끝까지 연결해 검증: 정상, 패치 변조 차단, 저장 불량 감지 |
| 설치 파일 | Mac 명령을 흉내 낸 환경에서 전체 실행 성공 |
| **실제 Photoshop·실제 Mac** | **미검증.** 이 개발 환경에 Mac과 Photoshop이 없습니다 |
| 정밀도(사람이 클린업한 정답 PSD와 비교) | **미측정.** 불통 원본 + 통과 정답 PSD 쌍이 필요합니다(`tools/eval_pairs.py`) |
