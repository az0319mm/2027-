# PSD 클린업 — macOS 설치 및 사용 가이드

코딩을 몰라도 따라 할 수 있도록 만든 안내서입니다. **Photoshop 플러그인 하나만** Load 하면 끝입니다.
Python, 터미널, 따로 켜 두는 프로그램은 **필요 없습니다** (v0.3.0 부터).

## 구성
- **Photoshop 패널(UXP 플러그인)** 하나에 모든 기능이 들어 있습니다.
  - 레이어 픽셀을 메모리로 읽고, 플러그인 안의 클린업 엔진(어패럴/인테리어)으로 고칠 곳을 계산합니다.
  - 고친 픽셀을 **복제본의 원래 위치**에 써 넣고, 바로 다시 읽어 맞는지 확인합니다.
  - 새 PSD로 저장하고 다시 열어 검증합니다.
- 인터넷으로는 아무것도 보내지 않습니다. 임시 파일도 만들지 않습니다.
- 디스크에 생기는 파일: **⑤를 눌렀을 때 `원본이름_CLEAN.psd`** 하나. (⑥을 누르면 `원본이름_QA.html` 보고서도)

## 준비물
| 항목 | 조건 | 확인 방법 |
|---|---|---|
| Mac | Apple Silicon(M1~) 또는 Intel, macOS 11 이상 | 화면 왼쪽 위  → 이 Mac에 관하여 |
| Photoshop | **2023 (24.4) 이상** | Photoshop → Photoshop 정보 |
| UXP Developer Tools | Adobe 무료 도구 | Creative Cloud 앱 → 모든 앱 → `UXP` 검색 → 설치 |

## 설치 (처음 한 번)
1. GitHub에서 **Code → Download ZIP**으로 받고 압축을 풉니다. 이 브랜치에서 받아야 합니다: https://github.com/az0319mm/2027-/tree/claude/photoshop-psd-cleanup-ermtuq
2. **Photoshop 개발자 모드**를 켭니다: Photoshop → 설정 → 플러그인 → **"개발자 모드 활성화"** 체크 → Photoshop 재시작. (이미 했다면 생략)
3. **UXP Developer Tools**를 열고 **Add Plugin**을 누른 뒤 압축을 푼 폴더의 `uxp-plugin/manifest.json`을 선택하고 **Load**를 누릅니다.
   - 예전 버전이 목록에 있으면 먼저 그 줄의 **•••** → **Remove** 한 뒤 새로 Add 하세요.
4. Photoshop 메뉴 **플러그인 → PSD 클린업**을 눌러 패널을 엽니다.
5. 패널에서 **"환경 확인"**을 누르면 칩, macOS, Photoshop 버전이 표시되고 "클린업 엔진: 플러그인 내장 ✅"이 나옵니다.

> 예전 버전(0.2.x)에서 `PSD 클린업 엔진 설치.command`를 실행한 적이 있다면, 더 이상 필요 없으니
> `예전 엔진 제거(선택).command`를 우클릭 → 열기로 한 번 실행해 백그라운드 엔진을 꺼도 됩니다. (안 해도 플러그인은 동작합니다)

## 사용 순서
1. 클린업할 PSD를 Photoshop에서 엽니다.
2. **모드**를 고릅니다.
   - **어패럴**: "반복된 1픽셀도 고치기"는 보고서에서 '의도적 반복'이 복사된 실수로 보일 때만 켭니다.
   - **인테리어**: 표현 방식(수채화, 색연필, 크레파스, 디지털 색면)을 고르고, 필요하면 "스캔 종이 배경 지우기"를 켭니다.
   - **리핏**: 해당 방향을 고릅니다.
3. **① 현재 PSD 분석**: 아무것도 고치지 않고 문제 목록만 봅니다.
4. **② 자동 클린업**: `원본이름_CLEAN`이라는 **복제본 문서**가 생기고, 확실한 오류만 고쳐집니다.
   - 큰 PSD(예: 4200×3600, 7레이어)는 계산에 20초~1분 걸리고, 그동안 Photoshop이 잠깐 멈춘 것처럼 보일 수 있습니다. 기다리면 됩니다.
   - 고친 직후 픽셀을 다시 읽어 엔진 계산과 비교합니다. 하나라도 다르면 **모두 취소**합니다.
5. **③ 전후 비교**: `원본이름_전후비교` 문서가 열립니다(저장되지 않음).
   - 레이어: 수정 전 / 수정 후 / 바뀐 곳(빨간 점·원). **'수정 후' 레이어의 눈 아이콘을 껐다 켜면** 전후가 바뀝니다.
   - 패널에 바뀐 곳의 좌표도 나옵니다. 다 보면 이 문서는 저장하지 말고 닫으세요.
6. **④ 남은 오류 재검사**: 복제본을 다시 검사해서 남은 문제를 보여 줍니다.
7. **⑤ 새 PSD로 저장**: 원본 옆에 `원본이름_CLEAN.psd`로 저장하고 다시 열어 검증합니다.
   - 레이어 구조, 캔버스, 프로파일, 픽셀을 확인합니다.
   - 검증에 실패하면 파일 이름에 `_VERIFY_FAILED`가 붙습니다.
8. **⑥ 검수 보고서 저장**(선택): PSD 옆에 `원본이름_QA.html`을 저장합니다. 누르지 않으면 만들지 않습니다.

**원본 PSD는 어떤 경우에도 바뀌지 않습니다.**

## 처리 규칙 요약
- **처리하는 레이어**: 일반 픽셀 레이어(RGB 8비트).
- **건너뛰고 보고만 하는 레이어**: 스마트 오브젝트, 텍스트, 조정·칠 레이어, 레이어 마스크가 있는 레이어, 잠긴 레이어, 16/32비트 문서.
- **수정 방식**: 블러, 리샘플링, 전체 필터는 쓰지 않습니다. 오류로 확정된 1~몇 픽셀만 **이미 주변에 있는 색**으로 고치거나 투명 처리합니다.
- **어패럴**:
  - 고치는 것: 의도하지 않은 1픽셀, 잘못 칠한 색, 회전으로 깨진 곧은 경계·대각선 경계, 분판(레이어 하나 = 색 하나) 사이 1픽셀 이동(구멍·겹침이 생기지 않게).
  - 지키는 것: 반복되는 의도적 1픽셀, 곡선 꼭짓점, 뾰족한 끝, 가는 선.
- **인테리어**:
  - 고치는 것: 모티브와 떨어진 잔여 점과 옅은 지우개 흔적, (선택 시) 스캔 종이 배경.
  - 지키는 것: 수채화 번짐, 붓 터치, 질감.
  - 보고만 하는 것: 외곽 종이색, 도장툴 흔적, 각진 외곽, 1px 직선 자국, 리핏 어긋남.

## 문제 해결
| 증상 | 해결 |
|---|---|
| 패널이 메뉴에 없음 | 개발자 모드를 켠 뒤 Photoshop을 재시작했는지, UXP Developer Tools에서 Load를 눌렀는지 확인 |
| "Plugin Load Failed" | UXP Developer Tools에서 예전 항목을 Remove 하고 새 ZIP의 `manifest.json`으로 다시 Add → Load |
| 파일 권한 질문 창 | "허용"을 누르세요(PSD 옆에 결과를 저장하기 위해 필요) |
| 오류 메시지가 나옴 | 패널 아래 글 상자를 캡처해서 보내 주세요 |

## 검증 현황 (솔직한 현황)
| 항목 | 상태 |
|---|---|
| 플러그인 내장 엔진 = 기존 Python 엔진 | 같은 입력에 **수정 픽셀까지 완전히 같은 결과**인지 자동 비교: 합성 사례 14종 + 실제 분판 PSD(28SS5-A002KGY03, 4200×3600) 2가지 설정 모두 일치. 속도: 그 PSD에서 약 16초(Python 약 86초) |
| 패널 전체 흐름 | 모의 Photoshop에서 끝까지 검증: 정상 저장, 패치 변조 차단, 저장 불량 감지, 전후 비교 문서, PSD 외 파일 생성 없음 |
| 실제 Photoshop에서 패널 Load·픽셀 읽기 | 사용자 Mac에서 확인됨(0.2.x) |
| **실제 Photoshop에서 0.3.0 전체 흐름** | **미검증.** 처음 실행 결과(캡처)를 보내 주시면 확인합니다 |
| 정밀도(사람이 클린업한 정답 PSD와 비교) | **미측정.** 불통 원본 + 통과 정답 PSD 쌍이 필요합니다 |
